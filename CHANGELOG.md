- Selected-paper research sessions and six scoped tools.
- Verified quotations, PDF content fingerprints, physical page navigation and coordinate highlights.
- Stable citation keys, BibTeX/BibLaTeX/CSL JSON export and local auto-export.
- Recursive folder import with content deduplication.
- Public-release cleanup: portable Python configuration, English/Chinese READMEs, AGPL license/notices, CI and publication privacy checks.

This release contains no private library, credentials, machine-specific installation scripts or session records.
